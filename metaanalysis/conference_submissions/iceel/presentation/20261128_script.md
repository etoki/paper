# 背景

## ▶ S3 ｜ [用語] Big Five

**Big Five** は、／人の性格を**5つの特性**で表すモデルです。〈間〉

**Openness**、新しいことへの好奇心。／**Conscientiousness**、まじめさと計画性。／**Extraversion**、外向性。／**Agreeableness**、協調性。／そして **Neuroticism**、不安や心配のしやすさです。〈間〉

対面の授業では、／**Conscientiousness が、成績といちばん強く関係する**ことが分かっています。〈間〉

## ▶ S6 ｜ [用語] Hofstede の文化次元

国の文化を比べるとき、／よく使われるのが、**Hofstede の文化次元**です。〈間〉

国の文化を、**6つの軸**で点数にします。／今日は、3つだけ紹介します。〈間〉

**Individualism**。／個人を重んじるか、集団を重んじるか。〈間〉

**Uncertainty Avoidance**。／あいまいさや、先の見えない状況を、どれだけ避けたいか。〈間〉

**Masculinity**。／競争や成果を、どれだけ重んじるか。〈間〉

**日本は、Uncertainty Avoidance が 92、／Masculinity が 95 です。**／どちらも、世界でもとても高い点数です。〈間〉

中国は、Uncertainty Avoidance が 30 です。／**日本と中国では、62点も違います。**〈間〉

# 方法

## ▶ S8 ｜ 方法

そして、その結果を、／**Hofstede と McCrae の2004年の研究**と比べました。／この研究は、**33か国**で、／国の文化の点数と、国の平均的な性格の関係を調べたものです。〈間〉

## ▶ S9 ｜ 結果1：予想と逆の Extraversion

まず、中国と日本の比較です。〈間〉

**Extraversion と成績の相関**は、／中国で **マイナス 0.074**、／日本で **マイナス 0.173** でした。〈間〉

## ▶ S11 ｜ 結果3：5つのうち3つが同じ向き

最後に、文化から考えられる方向との比較です。〈間〉

# 考察

## ▶ S12 ｜ なぜ Neuroticism がプラスなのか（仮説）

ひとつの説明は、／日本の **Uncertainty Avoidance の高さ**です。〈間〉

Hofstede は、1986年に、／Uncertainty Avoidance が高い社会では、／**学生は、決まった形の学びを好み、／正確に解くことが評価される**、と書いています。〈間〉

そういう環境では、／**少し心配性な学生のほうが、／ていねいに、まじめに勉強する**のかもしれません。〈間〉

でも、これは**仮説**です。〈間〉

どちらの値も小さく、**統計的に有意ではありません。**〈間〉

そして、文化の点数は**国のデータ**です。／でも、相関は**国の中の、一人ひとりのデータ**です。／**国のレベルの関係が、個人のレベルでも成り立つとは限りません。**〈間〉

## 質疑用メモ（発表では話さない）

- **ECEL の訂正との関係（聞かれたら）**：ECEL（EL-095）で「非同期型で E がマイナス」と報告した差は、訂正後 F(1, 6) = 8.07, p = .030 で、A-28 Yu と A-31 Rivers の2本を除くと消える（p = .82）。ICEEL の地域差（p = .009）も同じ2本でできている。2本とも非同期型なので、地域と形式は分けられない。訂正は OSF に公開（EL-095 の author's correction）。
- **アジア以外の E（主要プール7本）**：A-01 +0.030、A-02 +0.051、A-22 +0.140、A-23 −0.025、A-29 +0.027、A-30 +0.099、A-37 0.000。マイナスは A-23 の −0.025 だけで、ほぼゼロ。
- **全体の数値の出どころ**：Asia r = −0.095（k = 2）vs non-Asia r = +0.050（k = 7）、Knapp–Hartung メタ回帰 F(1, 7) = 12.94, p = .009。プレプリントの Q_between = 46.43 や Asia r = −0.131 は、β→r 変換と検定方法を直したため使わない。
- **アジア2本のプール値（Table 1）**：C r = 0.110 [−0.045, 0.260]、N r = 0.089 [0.005, 0.171]、E r = −0.095 [−0.541, 0.393]、O 0.155、A 0.319（O・A は I² ≈ 95%）。REML + HKSJ。
- **なぜ検定しないのか**：k = 2 だと残差自由度 df = 0。回帰の直線は2点をぴったり通り、傾き＝（日本 − 中国の Fisher z 差）÷（文化スコアの差）になるだけ。6つの次元はすべて同じ1つの対比を言い換えているにすぎない（Table 2 は記述のみ）。
- **Hofstede スコア**：The Culture Factor Group（旧 Hofstede Insights）の現行値（2023年に IDV・LTO 改訂）、2026年10月27日取得。日本 PDI 54, IDV 62, MAS 95, UAI 92, LTO 100, IND 42。中国 PDI 80, IDV 43, MAS 66, UAI 30, LTO 77, IND 24。
- **Hofstede & McCrae 2004（Table 1 のゼロ次相関、33か国）**：IDV × E = +.64、UAI × N = +.58、MAS × N = +.57、UAI × A = −.55、PDI × C = +.52、MAS × O = +.40。各特性で最も強い次元の符号を「国レベルの参照方向」として使った（Table 4）。予測ではなく参照点。
- **日本2本の詳細（Table 3）**：Tokiwa 2025 は N = 103、高校3年、StudySapuri、BFI-2-J 60項目、Spearman ρ（学習行動）。Rivers 2021 は N = 149、大学2年、Moodle、TIPI-J 10項目、Pearson r（成績）。Rivers の r：O −0.066、C +0.144、E −0.173、A +0.118、N +0.107（n.s.）。Tokiwa の ρ：C +0.34〜+0.35、A +0.23、N +0.17（n.s.）、E は Assertiveness +0.26／Sociability −0.23 で混在。
- **Neuroticism の比較先**：Mammadov 2022 のアジアサンプル ρ = −0.19（アジアは全特性で他地域より相関が大きい：C ρ = 0.35、E ρ = 0.16）。Poropat 2009 も N はほぼゼロ〜負。
- **Japan の N が高い根拠（聞かれたら）**：Schmitt et al. 2007 で日本の N 平均 57.87 は 56か国中最高。Allik & McCrae 2004 では日本は他の東アジアとまとまらない。
- **Hofstede 批判を聞かれたら**：McSweeney 2002（生態学的誤謬・IBM サンプル）を認める。ただし UAI はヨーロッパの代表サンプルで再現されている（Minkov & Hofstede 2014）。国レベルの代理指標としてのみ使った、と答える。
- **韓国・台湾は？**：今回のプールには、成績との相関 r を取り出せる研究がなかった。今後の課題として、韓国・台湾のサンプルを集めたい。
- **Big Five は日本に合うのか？**：Cheung et al. 2003 の指摘（西洋由来の Big Five はアジアの文化特有の性格構造を捉えきれない可能性）を限界として認める。

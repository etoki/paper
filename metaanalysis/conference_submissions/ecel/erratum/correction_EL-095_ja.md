# 【参考訳】訂正：Modality matters for Extraversion（ECEL 2026, EL-095）

送信するのは英語版 `correction_EL-095.docx` です。この日本語訳は内容確認用です。表の数値は英語版と同じなので、ここでは要点だけ載せています。

## 概要

掲載後、統計分析に誤りがあることが分かった。

- 表2の授業形式の検定方法が不適切だった
- 表3の交互作用モデルが、独立でない観測値を独立として扱っていた
- 研究間のばらつき（τ²）を小さく見積もっていた
- 表1の神経症傾向の行が、以前の草稿の値のまま残っていた

誠実性の結果は変わらない。非同期とミックス型で外向性が違うという結果は、名目上はまだ有意だが、報告したより弱く、2本の研究に依存している。確立した効果ではなく、今後検証すべき仮説として読むべきである。誤りをお詫びする。

## 1. 授業形式の検定（表2）

公開版の Q_between は、HKSJ 補正をかけた小さなグループの標準誤差を、大標本向けのカイ二乗分布に当てはめていた。これは標準的な方法ではない。表1の信頼区間（小標本向けの t 分布）とも整合しない。

1グループ3〜5研究という少なさを考え、Knapp–Hartung 補正つきの混合効果メタ回帰（F 検定）で計算し直した。従来の大標本向けの検定ならもっと小さい p 値が出るが、研究数がこれほど少ないと、偶然を有意と誤る確率が高くなることが知られている。

| 特性 | 公開版 | 訂正後 |
|---|---|---|
| 外向性 | Q = 17.60, p < .001 | F(1, 6) = 12.95, p = .011 |
| 協調性 | p = .070 | p = .057 |
| 開放性・誠実性・神経症傾向 | 有意差なし | 有意差なし（p ≥ .10） |

## 2. 交互作用モデル（表3）の撤回

42行のデータは9本の研究から来ている（1研究が最大5特性分の行を出す）。それを独立として扱っていたので、p 値（p = .009、全体検定 p = .0085）は無効。

さらに、外向性×ミックスの係数 +0.385 は「外向性の差 +0.159」から「開放性の差 −0.226」を引いたもので、外向性だけの差ではなかった。表3と、それに基づく記述はすべて撤回し、表2の特性ごとの検定に置き換える。

## 3. τ² の推定と表1

REML の計算が τ² を小さく見積もっていたため、正確な REML で計算し直した（PyMARE という既存ライブラリの結果と一致を確認）。表1の神経症傾向の2行は、授業形式を再分類する前の草稿の値だったので直した（図2はもともと正しい値だった）。

- 神経症傾向以外の変化は最大 0.019（誠実性・非同期：0.190 → 0.209）
- 3.1節の値の変化は最大 0.003

## 4. 外向性の結果の頑健性（3.5節）

非同期で外向性がマイナスになった3研究のうち、マイナスなのは A-28 Yu（中国、r = −0.126）と A-31 Rivers（日本、r = −0.173）の2本だけ。A-01 Abe（米国）は +0.030。

| 除いた研究 | 検定結果 |
|---|---|
| A-28 | p = .130（有意でなくなる） |
| A-31 | p = .044 |
| 2本とも | p = .819（差はほぼゼロ） |
| β変換研究（A-28, A-30） | p = .208（有意でなくなる） |

公開版の「どのシナリオでも頑健」は誤り。マイナスの2本がどちらも東アジアなので、授業形式の影響か地域の影響かは区別できない。

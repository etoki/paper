# OSF project text: Author's correction to ECEL 2026 paper EL-095

## Title

Author's correction to: Modality matters for Extraversion: A Big Five meta-regression in online learning environments (ECEL 2026)

## Description

This project contains the author's correction to Tokiwa, E. (2026). Modality matters for Extraversion: A Big Five meta-regression in online learning environments. Proceedings of the 25th European Conference on e-Learning (ECEL 2026), Vol. 25, No. 1, pp. 464–471. https://doi.org/10.34190/ecel.25.1.4996

After publication, the author found errors in the statistical analysis: the modality moderator test used an inappropriate procedure, the trait × modality interaction model treated non-independent observations as independent, two regression coefficients were converted to correlations with an incorrect formula, the between-study variance was under-estimated, and two rows of Table 1 came from an earlier draft. The publisher was asked to replace the paper or publish a correction, and replied that changes were no longer possible, so the correction is posted here by the author.

The Conscientiousness findings are unchanged. The Extraversion difference between asynchronous and mixed-online courses is much weaker than reported (F(1, 6) = 8.07, p = .030, rather than Q = 17.60, p < .001), depends on two East Asian studies, and should be read as a hypothesis. The interaction model (Table 3) is withdrawn.

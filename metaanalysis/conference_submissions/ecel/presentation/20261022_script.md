## ▶ S10 ｜ 統計モデル

統計モデルは、2つのパートがあります。〈間〉

**パート1。**／特性ごと、modality ごとに、／random-effects pool を計算しました。／τ² は REML、／信頼区間は HKSJ です。／これで、／cell ごとの r と 95% CI が出ます。〈間〉

**パート2。**／long-format の interaction model を作りました。／42 の observation、／5つの特性、／2つの modality レベルです。／weighted OLS で、／weights は 1 / (v + τ²) です。〈間〉

design には、／trait dummy、／modality dummy、／trait × modality の interaction 4つが入ります。／メインの推論は、／**4つの interaction 項に対する joint Wald カイ二乗検定**です。〈間〉

# 結果

## ▶ S11 ｜ Table 1: Modality-stratified pools

さて、結果です。／Table 1 をご覧ください。〈間〉

いちばん大事な数字は、**Extraversion の Q_between** です。〈間〉

**Q = 17.60、／p < .001。**／非常に有意です。〈間〉

Agreeableness は trend-level です。／Q = 3.28、／p = .070。〈間〉

Conscientiousness、Neuroticism、Openness は、**有意ではありません。**〈間〉

つまり、／modality の story は、／**特性ごとに違う**ということです。／全特性に効く話ではありません。〈間〉

---

## ▶ S12 ｜ Figure 2: Extraversion が符号を変える

このスライドが、本日いちばん大事なスライドです。〈間〉

**非同期（asynchronous）**の cell では、／Extraversion は **負**です。／r = −0.121。／信頼区間はゼロをまたぎますが、／点推定は、はっきり負の側にあります。〈間〉

**ミックス（mixed-online）**の cell では、／Extraversion は **正**です。／r = +0.059。〈間〉

modality が変わると、／**Extraversion は符号を反転させます。**〈間〉

これが、trait-only pool が 0.002 だった理由です。／負と正が、ちょうど打ち消し合っていました。〈間〉

**preprint の "ゼロ" の結果は、／本当は、ひとつの実質的な効果を隠していたのです。**〈間〉

---

## ▶ S13 ｜ Interaction model: Wald test

これは、interaction model でも確認できるでしょうか。／はい、できます。〈間〉

Extraversion × Mixed の係数は、**Fisher z で +0.385**。／p = 0.009 です。〈間〉

4つの interaction 項すべてに対する joint Wald test は、／**χ²(4) = 13.64、／p = 0.0085**。〈間〉

2つの独立した検定が、同じことを言っています。〈間〉

**modality は、Extraversion にとって、／本物の moderator です。**〈間〉

---

## ▶ S14 ｜ Conscientiousness は変わらない

ところが、Conscientiousness を見ると、／話はまったく違います。〈間〉

非同期の r = 0.190。／ミックスの r = 0.180。〈間〉

差は、わずか 0.010。／Q_between の p = 0.903。／これは、／検定が "ほぼ null" といえるくらいの値です。〈間〉

**Conscientiousness は、modality をまたいでも頑健です。**〈間〉

preprint のヘッドライン、／「Conscientiousness がオンライン学習のいちばんの予測因子」、／これは、／**より細かい modality 解像度でも、保たれます。**〈間〉

ですので、／これは **"ツースピード" の story** です。〈間〉

**Conscientiousness は安定。／Extraversion は modality 依存。**〈間〉

## ▶ S15 ｜ Course designer への含意

これは、／オンライン講座の設計者にとって、／どういう意味を持つでしょうか。〈間〉

メッセージは、**非対称**です。〈間〉

**Conscientiousness について。**／self-regulation を支援する設計をしてください。／非同期でも、ミックスでも、同じように効きます。／modality を変えても、ここは変わりません。〈間〉

**Extraversion について。**／**非同期のみの講座では、／"見えないハンデ" を予想してください。**／外向的な学生は、／ライブなしでは成績が下がる可能性があります。〈間〉

ライブセッションを加えると、／たとえ週に数回でも、／Extraversion のハンデは消えます。／そして、／むしろ **アドバンテージ**になるかもしれません。〈間〉

外向的な学生にとっては、／**ミックスのほうが、完全非同期よりも良い**。／これは、／性格を変える話ではなく、／**設計の話**です。〈間〉

## 想定質問と準備回答（日本語で先に組み立て、英語版は `_en.md` に）

**Q1. k = 6 と 5 は少なすぎないか？**
はい、おっしゃる通りです。／この数字は小さい。／ですので、この結果は **confirmatory ではなく exploratory** だと位置づけています。／ただし、interaction model の p = 0.009、／Wald test の p = 0.0085 が出ています。／報告する価値のあるパターンだと考えています。／今後、より大きい k で検証されるべきです。

**Q2. Modality coding が主観的ではないか？**
妥当なご指摘です。／4本の論文で modality が空欄で、／PDF から再コーディングしました。／4つのコーディング判断は、すべて audit log に残しています。／別のコーディングでも、／Extraversion の符号反転は robust に出ます。／second coder を入れれば、より強い結果になります。／次版で加える予定です。

**Q3. なぜ asynchronous で Extraversion が負になるのか？**
正直に申し上げると、／この論文はメカニズムには答えていません。／ただし、ひとつの仮説はこうです。／非同期学習は、／self-regulation を強く要求します。／外向的な学生は、／社会的なやり取りを好む傾向があり、／独りで作業するときに苦労するかもしれません。／ミックスでは、／ライブセッションが社会的な手がかりを提供し、／成績が良くなる。／ただし、これは仮説で、／データからは証明できません。

**Q4. 同じ結果は synchronous でも出るか？**
これにはお答えできません。／pool の中で、完全同期の研究は1本だけです。／narrative にのみ報告しています。／直接テストするには、／もっと synchronous の研究が必要です。

**Q5. 文化的な差 (Asia vs non-Asia) との関係は？**
良いご質問です。／親の preprint は、／Asia × Extraversion に強い効果を見つけています。／この interaction model には region を入れていません。／k の制約があるからです。／2つの moderator は相互作用するかもしれません。／ICEEL 2026 に、／within-Asia 分析の別論文を出しています。

**Q6. この結果は policy にどう使えるか？**
慎重にお願いします。／これは、k の小さいメタ分析1本の結果です。／学生のスクリーニングや、／個人のラベリングには使わないでください。／正しい使い方は、／**design level** です。／非同期のみの講座を計画しているなら、／ライブセッションを少し加えてください。／効果量は中程度なので、／得られるものも中程度です。

# 01 ｜ 原典の棚卸しと、数値の正典化

**目的**: 発表で出す数字を、あとから1つ残らず出所に辿れる状態にする。
ここを飛ばすと、スライドを作り直すたびに数字の検算が発生する。

**入力**: 自分の論文、解析結果（`res/*.csv` など）、引用する他者の論文PDF
**出力**: 数値の正典ファイル（例 `CANONICAL_RESULTS.md`）、`docs/` に揃った原典PDF、不足リスト

---

## プロンプト A ｜ 手持ちの棚卸しと、足りない原典の洗い出し

```text
発表資料を作る前に、素材の棚卸しをしてください。

1. 私の論文（パス）を読み、発表で使えそうな結果を一覧にしてください。
2. 論文が引用している文献のうち、発表で「根拠」として示す価値があるものを選び、
   原本PDFがリポジトリにあるか確認してください。
3. 原本が無いものを「アップロードしてほしいリスト」として、
   なぜそれが必要か（どの主張を支えるか）とあわせて挙げてください。

注意：
- Webから取りに行けない場合があります（この環境のネットワークポリシー）。
  取得に失敗したら、その旨を言って私にPDFをコミットさせてください。勝手に記憶で補わないこと。
- 同じ姓の著者の別論文を取り違えないこと。著者名・年・誌名・巻号頁が
  論文の引用リストと一致しているか、PDFの中身を開いて確認してから「ある」と言うこと。
```

## プロンプト B ｜ 数値の正典をつくる

```text
発表で出す数字の単一の真実源をつくってください。

- 解析結果のCSVから、N、R²、ΔR²、F、p、β、α、VIF などを転記した
  CANONICAL_RESULTS.md を作る（既にあるなら、それを唯一の参照先とする）。
- 以後、原稿にもスライドにも、ここに無い数字は書かない。
- 他者の論文から引く数字は、PDFの該当箇所を実際に開いて読み取ること。
  要旨やタイトルからの推測で書かない。
```

## プロンプト C ｜ 出典対応表

```text
画面構成ドキュメントの末尾に「数値の出典対応表」を作ってください。
列は「スライド番号 / 数値 / 出所」。出所は CANONICAL_RESULTS.md の節番号か、
原典PDFのファイル名です。スライドに出る数字はすべてこの表に載っていること。
```

---

## 受け入れ基準

- [ ] スライドに出る数字が、1つ残らず出典対応表にある
- [ ] 他者の論文の数値は、PDFの本文・表を実際に読んで取った（要旨からの推測ではない）
- [ ] 著者名・年・誌名・巻号頁が原典と一致している
- [ ] 日本語の著者名の漢字を原典で確認した

## 実際に起きた失敗

| 起きたこと | 教訓 |
|---|---|
| `nielsen2014.pdf` が同姓の別人による別分野の論文（機能性運動障害の理学療法）だった | ファイル名が合っていても中身を開いて確認する |
| 著者名を「統先生」と書いた。正しくは **鄧 科（とう か）** | 日本語著者の漢字は原典で確認する。読めなければアルファベット表記にする |
| 厚労省サイトと学会サイトがプロキシに拒否された | 取得失敗は隠さず報告し、PDFをコミットしてもらう |
| 目撃者への影響を「2.4倍いる」とだけ書いた | 件数だけでは「だから何？」になる。影響の大きさを示す文献（メタ分析・縦断研究）まで取りに行く |

# 学会発表の資料をつくるプロンプト集

**目的**: 自分の論文から学会発表（読み上げ原稿＋スライド）を組み立てる作業を、
毎回ゼロから指示し直さずに済むよう、工程ごとのプロンプトとして固定する。

**つくられた経緯**: 第24回メンタルケア学術大会（2026-10-04）の発表
「データが示すハラスメントと性格特性のつながり ― HEXACOからメンタルケアを考える ―」
を実際に作った工程を、そのまま再利用できる形に起こしたもの。
成果物は `../20261004_script.md`（読み上げ原稿）と `../20261004_slides.md`（画面構成）、
および Google スライドのデッキ。

---

## 全体の流れ

```
01 棚卸しと正典化  →  数字の単一の真実源を決める（ここを飛ばすと後で全部やり直し）
        ↓
02 スクリプト      →  話す内容を先に全部書く（スライドはまだ作らない）
        ↓
03 時間           →  実測する。推定で書かない
        ↓
04 画面構成       →  スクリプトと1対1で対応させた別ドキュメント
        ↓
05 書き込み       →  Google スライドへ。書いたら必ず読み戻す
        ↓
06 レイアウト検証  →  PDFに書き出して機械チェック＋目視
```

`07` は全工程に通しでかかる規範（言い過ぎを防ぐルール）。
各工程のあいだで必ずユーザーのレビューを挟む。特に 02 → 03 の前と、04 → 05 の前。

| # | ファイル | 何をするか |
|---|---|---|
| 01 | [01_sources.md](01_sources.md) | 原典を集め、数値の単一の真実源をつくる |
| 02 | [02_script.md](02_script.md) | 読み上げ原稿を先に書く |
| 03 | [03_timing.md](03_timing.md) | 所要時間を実測し、持ち時間に合わせる |
| 04 | [04_slide_spec.md](04_slide_spec.md) | 画面構成ドキュメントを書く |
| 05 | [05_write_slides.md](05_write_slides.md) | Google スライドへ書き込む |
| 06 | [06_layout_qa.md](06_layout_qa.md) | レイアウト崩れを検出して直す |
| 07 | [07_review_rules.md](07_review_rules.md) | 言い過ぎを防ぐ（全工程に適用） |

## ツール

| ファイル | 用途 |
|---|---|
| [tools/measure_script_timing.py](tools/measure_script_timing.py) | 原稿の所要時間をスライド別・ブロック別に実測 |
| [tools/check_slide_layout.py](tools/check_slide_layout.py) | PDF書き出しから、はみ出し・重なり・表の詰まりを検出 |

```bash
python3 prompts/tools/measure_script_timing.py 20261004_script.md --budget 30
python3 prompts/tools/check_slide_layout.py deck.pdf --render-dir /tmp/pages
```

## 最初に一度だけ渡す前提プロンプト

工程に入る前に、これを渡して共有前提をつくる。

```text
これから学会発表の資料を作ります。まず前提を共有します。

【発表】
- 学会名／回次：
- 日付：
- 持ち時間：発表◯分＋質疑◯分
- 演題：
- 聴衆：（例：臨床・支援職が中心。統計の専門家ではないが、学術大会なので根拠は求められる）

【素材】
- 発表のもとになる自分の論文：（リポジトリ内のパス）
- 数値の正典：（例：harassment/CANONICAL_RESULTS.md）
- 引用する他者の論文PDF：（ディレクトリ）

【進め方の約束】
- 工程は「原典の確認 → 読み上げ原稿 → 時間の実測 → 画面構成 → スライド書き込み → レイアウト検証」の順。
  前の工程を私がレビューしてから次へ進むこと。
- 原稿を先に完成させる。スライドはそのあと。
- 数字は必ず正典か原典PDFに当たる。出所を言えない数字はスライドに載せない。
- 私が専門的な誤りを指摘したら、その主張は全資料から消すこと。言い換えて残さない。
```

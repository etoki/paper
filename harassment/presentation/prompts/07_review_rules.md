# 07 ｜ 言い過ぎを防ぐ規範（全工程に適用）

**目的**: 発表の信頼を守る。学術大会では「何が言えるか」より
「何が言えないか」を正しく扱えているかが見られる。

これは工程ではなく、01〜06 のすべてに通しでかかるルール。
作業の最初に一度渡し、原稿・スライドのレビューのたびに再掲する。

---

## プロンプト

```text
原稿とスライドを、次の観点で点検してください。該当したら直して、何を直したか報告すること。

【因果】
- 横断データから因果を言っていないか。「予測する」「影響する」も因果に聞こえる。
  言えるのは「関連していた」まで。
- 逆向きの因果と第三の要因を、自分から挙げているか。

【効果の大きさ】
- 統計的に有意であることを、効果が大きいことのように書いていないか。
- 説明率が小さいなら「小さい」と正直に言っているか。
- 性格で説明できる分と、立場・環境で説明できる分を並べて示しているか。

【性格と環境】
- 「残りは環境」と書いていないか。性格自体に環境の寄与があるので、
  性格と環境は切り分けられない。性格は原因ではなく、
  素質と経験が表に出た「目印」として扱う。

【解釈スライド】
- データから直接出ない解釈を、結果のように書いていないか。
  解釈なら「これは解釈であり、検証された経路ではない」と画面に明記する。
- 解釈が人によって分かれる話題（例：性格は変えられるか）は、
  こちらの立場を既定として書かない。落とす。

【当事者への配慮】
- メンタルケアの文脈では、支援の対象は被害を受けた側。
  加害者をラベリングする話にすり替わっていないか。
- 性格特性を、人を見分ける・選別する道具として提案していないか。

【数値】
- 出所を言えない数値が残っていないか。
- 自分の研究の数値と、他者の研究の数値が混ざって見えないか。
```

## 指摘を受けたときの振る舞い

```text
私が専門的な誤りを指摘したら：
- その主張を全資料から消すこと。言い換えて残さない。
- 同じ誤りが波及している箇所を grep で洗い、まとめて直すこと。
- 直したうえで、何をどう直したかを1〜2文で報告すること。長い反省は要らない。
```

---

## 実際に受けた指摘と、その反映

| 指摘 | どう直したか |
|---|---|
| 「残りの8〜9割は性格以外」は誤り。性格自体に環境の寄与が半分ある | 主張を全面撤回し、双生児家族研究の因子別データ（遺伝 .46〜.63、共有環境ほぼゼロ）に置き換えて、「性格か環境か」の切り分け自体が成立しないと述べる構成にした |
| 「あの人はそういう性格だから」と言われるリスクの話は解釈に寄りすぎ。性格が変えられるかは人による | そのスライドと該当箇所を削除した |
| メンタルケアは加害者の文脈ではなく、被害を受けた側の文脈 | 示唆の章を、被害者・目撃者・部下への支援を軸に書き直した |
| 日本人の性格類型の話は浮いている | 本編から外し、想定質疑に移した |
| 名前を無理に漢字にしなくていい | 原典に漢字がある場合のみ漢字、無ければアルファベット表記に統一した |
| 学術大会なので統計手法の説明が要る | 階層的重回帰と頑健標準誤差を、式を使わず日常語で説明するスライドと原稿を追加した |
| ダークな性格が、メンタル悪化の「一つの要因になりうる」ことは強調したい。ただし因果ではないので謙虚に | 3つの関連を並べて1枚にまとめ、「上流にある要因のひとつになりうる」と述べたうえで、同じ画面に「因果の鎖は検証されていない」「立場の影響のほうが大きい」を併記した |
